# 🐍 Snake Game

لعبة Snake بسيطة بـ HTML5، جاهزة للتحويل لـ APK.

## 🎮 اللعب
- استخدم أزرار الاتجاهات على الشاشة
- أو اسحب بإصبعك
- أو استخدم لوحة المفاتيح (كمبيوتر)

## 📥 التحميل كـ APK
1. روح على [Actions](../../actions)
2. اختار آخر build ناجح
3. حمّل `snake-apk`
4. فك الـ zip وثبّت `app-debug.apk`

## 🛠️ التقنيات
- HTML5 Canvas
- JavaScript
- Capacitor (لتحويل الويب لـ APK)
